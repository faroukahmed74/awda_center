1. Global app bar — every icon

شريط التطبيق العلوي — شرح كل أيقونة

These icons appear on almost every authenticated screen (Appointments, Income, Reports, Chat, …). Same behavior on Web, Android, and iOS.

  • 💬
    Messages / Chat
    Opens clinic messaging (1:1, groups, broadcast). Badge may show unread.
  • 🔔
    Notifications
    Opens in-app panel: upcoming appointments, audit items (admin), open todos. Desktop = dialog; phone = bottom sheet.
  • ↻
    Refresh (Web)
    Reloads the page to fetch the latest web build / data. Tooltip: “Refresh (get latest update)”.
  • 🌐
    Language
    Toggles Arabic ↔ English. Full UI RTL when Arabic. Tooltip shows the language you will switch to.
  • 🌙 / ☀️
    Theme
    Toggles Dark ↔ Light. Moon icon in dark mode; sun icon in light mode. Preference is persisted.
  • ←
    Back
    Returns to previous route / dashboard.
  • ＋
    Context add
    Screen-specific create action (new appointment, income, expense, user, room…).
  • ☰
    Drawer / menu
    Dashboard hamburger opens navigation filtered by the user’s roles & privileges.

Language & theme in practice

Language switch rebuilds all labels (status chips, filters, finance headers). Theme switch repaints surfaces, cards, and charts for day/night clinic floors.

2. Appointments — every button, filter, legend & cell

شاشة المواعيد — كل زر وفلتر وخلية

2.1 App-bar actions (this screen)

  • ←
    Back
    Leave appointments.
  • 💬🔔↻🌐🌙
    Global icons
    Messages, Notifications, Refresh, Language, Theme — see §1.
  • ☰ filters
    Show / Hide filters
    Icon filter_list / filter_list_off. Collapses status chips, date chips, dropdowns, and count row to give the list more space.
  • ＋
    Create appointment
    Opens the full booking dialog: patient, supervising doctor, performing doctor, room, date/time, services, package, cost, discount %, notes, VIP star, extra slot.

2.2 Status filter chips

ApologizedAbsent with cause (اعتذار).
AbsentAbsent without cause / no-show style absence.

2.3 Period chips & List / Schedule toggle

  • Day
    Day filter
    Single calendar day (with prev/next day & date picker).
  • Month
    Month filter
    Whole month of appointments.
  • Year
    Year filter
    Whole year.
  • ☰ List
    List view
    Vertical cards: patient • supervisor / performer, time, status, service, notes, ⋮ menu.
  • ▦ Schedule
    Schedule view
    Day grid: time rows (every 30 min 00:00–23:30) × room columns. Shows conflicts visually; cancelled/absent don’t keep the room.

List vs Schedule: List is best for search & status ops. Schedule is the floor board — who is in which room at which half-hour. Toggle lives in the filter row as a segmented control with list / calendar icons.

  • ‹ ›

3.6 Summary cards & lists

  • 💰
    Total Income card
    Sum of filtered income (EGP).
  • 📈
    Net Profit card
    Income − expenses for the filter.
  • 🧾
    Total Expenses card
    Sum of filtered expenses.
  • 📊
    Income by doctor / Expense by doctor
    Breakdown blocks under the cards when data exists.
  • ⋮
    Row menu
    Edit or Delete a record.

Each income row shows: amount, source, date/time, notes, patient, doctor, payment status (Paid / Partial / Prepaid / Not paid).
Each expense row shows: amount, date/time, category, description, paid-by-doctor, optional recipient (salary).

Search box filters free text across visible fields. Counter text under filters: Income: N · Expenses: M.

4. Finance summary — every field & cell

الملخص المالي — كل عمود وخلية

4.1 Header controls

  • Month / Year
    Period selectors
    Choose month & year for the sheet.
  • Month / Quarter / 6 months / Year
    Range mode
    Aggregates months; config scales for multi-month ranges.
  • Target
    Clinic target
    Editable money target for the period.
  • 30% factor
    Percent factor
    Usually 0.3 — drives “30% Target” column = income × factor.
  • 📄 PDF
    Export PDF
    Bilingual PDF with Amiri + Arabic reshaper.
  • 💾 Save
    Save config
    Persists target, rates, slices, doctor order for the month.

8. ملخص عربي

  • قائمة المواعيد للبحث والحالات · جدول المواعيد للغرف ونصف الساعة
  • اللغة عربي/إنجليزي مع RTL · الثيم فاتح/غامق
